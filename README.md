# Patient_Readmission_Risk_Predictor
Predict hospital readmission risk using XGBoost + PDF report generation

Predicting Readmission Risk
This application leverages machine learning to predict the likelihood of patient readmissions, specifically for high-risk individuals. By estimating the readmission risk for each patient, healthcare providers can prioritize care and interventions for those most at risk, ultimately improving patient outcomes.

Key Features:
Readmission Risk Prediction: The app predicts the likelihood of a patient being readmitted based on various features like prior inpatient admissions, medical history, and more.

Risk Scores: Each prediction includes a risk score, which reflects the likelihood of readmission for the patient.

This tool aims to assist healthcare professionals in identifying high-risk patients, allowing for more focused follow-up care and timely interventions to reduce unnecessary readmissions.
